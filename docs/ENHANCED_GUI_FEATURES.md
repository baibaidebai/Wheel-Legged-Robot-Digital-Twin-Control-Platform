# 增强版GUI功能详解

## 🎨 界面布局

增强版GUI采用清晰的分区布局，每个区域负责不同的配置功能。

---

## 📋 界面区域说明

### 1. 标题栏
```
┌─────────────────────────────────────────┐
│   🤖 轮腿机器人仿真启动器                │
│   支持 Gazebo 和 MuJoCo 仿真器          │
└─────────────────────────────────────────┘
```

**功能：**
- 显示应用程序名称
- 显示支持的仿真器

---

### 2. 仿真器选择区域
```
┌─────────────────────────────────────────┐
│ 🎮 仿真器选择                            │
├─────────────────────────────────────────┤
│ ○ Gazebo Harmonic - 完整物理仿真        │
│ ○ MuJoCo - 高性能物理引擎               │
└─────────────────────────────────────────┘
```

**功能：**
- 选择使用Gazebo或MuJoCo
- 切换时自动显示对应的选项区域

**使用提示：**
- Gazebo：适合完整系统测试、ROS2集成
- MuJoCo：适合强化学习训练、高性能仿真

---

### 3. 机器人模型区域
```
┌─────────────────────────────────────────┐
│ 📦 机器人模型                            │
├─────────────────────────────────────────┤
│ 模型文件夹: [RM_Serial...▼] [浏览...]  │
│ URDF文件:   [RM_Serial...▼]            │
│ MJCF文件:   [RM_Serial...▼]            │
└─────────────────────────────────────────┘
```

**功能：**
- **模型文件夹**：选择机器人模型目录
  - 自动扫描 `src/model/` 下的所有文件夹
  - 支持浏览器选择自定义路径
  
- **URDF文件**：Gazebo使用的模型文件
  - 自动扫描选中文件夹的 `urdf/` 目录
  - 列出所有 `.urdf` 文件
  
- **MJCF文件**：MuJoCo使用的模型文件
  - 自动扫描选中文件夹的 `mjcf/` 目录
  - 列出所有 `.xml` 文件

**使用提示：**
1. 先选择模型文件夹
2. URDF和MJCF列表会自动更新
3. 根据仿真器选择对应的文件

---

### 4. 世界环境区域
```
┌─────────────────────────────────────────┐
│ 🌍 世界环境                              │
├─────────────────────────────────────────┤
│ ☑ 使用默认世界环境                       │
│ 世界文件: [wheel_legged...▼] [浏览...] │
└─────────────────────────────────────────┘
```

**功能：**
- **使用默认世界**：使用内置的默认环境
  - 包含地面、光源等基本元素
  - 适合大部分测试场景
  
- **自定义世界**：选择自定义环境文件
  - 自动扫描 `src/wheel_legged_control/worlds/`
  - 支持浏览器选择 `.world` 文件

**使用提示：**
- 勾选"使用默认世界"时，世界文件选择被禁用
- 取消勾选后可以选择自定义世界

---

### 5. Gazebo选项区域
```
┌─────────────────────────────────────────┐
│ ⚙️ Gazebo 选项                          │
├─────────────────────────────────────────┤
│ 启动模式: ○安全 ○简单 ○标准             │
│ ☑ 强制软件渲染 (解决闪屏问题)           │
│ ☐ 详细输出 (Verbose)                   │
└─────────────────────────────────────────┘
```

**功能：**
- **启动模式**：
  - 安全模式：禁用硬件加速，虚拟机推荐
  - 简单模式：基础功能，快速测试
  - 标准模式：完整功能，物理机使用
  
- **强制软件渲染**：解决Gazebo闪屏问题
  - 虚拟机环境推荐勾选
  - 可能降低性能但提高兼容性
  
- **详细输出**：显示调试信息
  - 帮助定位问题
  - 查看详细的启动日志

**使用提示：**
- 虚拟机：安全模式 + 软件渲染
- 物理机：标准模式
- 遇到问题：勾选详细输出

---

### 6. MuJoCo选项区域
```
┌─────────────────────────────────────────┐
│ ⚙️ MuJoCo 选项                          │
├─────────────────────────────────────────┤
│ ☐ 全屏模式                              │
│ 帧率 (FPS): [60▲▼]                     │
└─────────────────────────────────────────┘
```

**功能：**
- **全屏模式**：沉浸式体验
  - 适合演示和展示
  - 按Esc退出全屏
  
- **帧率设置**：30-120 FPS可调
  - 默认60 FPS
  - 高帧率更流畅但消耗更多资源
  - 低帧率更稳定

**使用提示：**
- 演示：全屏模式
- 训练：降低FPS节省资源
- 可视化：提高FPS获得流畅体验

---

### 7. 底部按钮栏
```
┌─────────────────────────────────────────┐
│  [🚀 启动仿真] [❓ 帮助] [❌ 退出]      │
└─────────────────────────────────────────┘
```

**功能：**
- **启动仿真**：根据配置启动仿真器
  - 显示确认对话框
  - 在新终端窗口中启动
  
- **帮助**：显示快速帮助信息
  - 功能说明
  - 常见问题
  - 快捷键
  
- **退出**：关闭GUI

## 🔄 工作流程

### 典型使用流程

1. **启动GUI**
   ```bash
   ./launch_enhanced.sh
   ```

2. **选择仿真器**
   - Gazebo 或 MuJoCo

3. **选择模型**
   - 选择模型文件夹
   - 选择对应的URDF/MJCF文件

4. **配置环境**（可选）
   - 使用默认世界或选择自定义

5. **配置选项**
   - Gazebo：模式、渲染
   - MuJoCo：全屏、帧率

6. **启动仿真**
   - 点击"启动仿真"
   - 确认配置
   - 等待启动

## 💡 使用技巧

### 技巧1：快速切换模型
1. 使用下拉菜单快速切换
2. 文件列表自动更新
3. 无需重启GUI

### 技巧2：测试不同配置
1. 保持GUI打开
2. 启动仿真后可以关闭仿真器
3. 修改配置后再次启动

### 技巧3：调试模式
1. 勾选"详细输出"
2. 查看终端窗口
3. 定位问题

### 技巧4：性能优化
**Gazebo：**
- 虚拟机 → 安全模式 + 软件渲染
- 物理机 → 标准模式

**MuJoCo：**
- 训练 → 降低FPS（30-60）
- 可视化 → 提高FPS（90-120）

## 🔍 界面元素说明

### 下拉菜单（Combobox）
- 点击展开选项列表
- 只能选择列表中的项目
- 自动更新可用选项

### 单选按钮（Radio Button）
- 一组中只能选择一个
- 用于互斥选项

### 复选框（Checkbox）
- 可以独立勾选/取消
- 用于开关选项

### 数字调节器（Spinbox）
- 点击上下箭头调整
- 可以直接输入数字
- 有最小/最大值限制

### 浏览按钮
- 打开文件/文件夹选择器
- 支持自定义路径

---

## 📊 状态指示

### 文件列表状态
- **有选项**：下拉菜单可用，显示文件列表
- **无选项**：下拉菜单为空，需要检查目录

### 按钮状态
- **可点击**：正常颜色，鼠标悬停变化
- **禁用**：灰色，无法点击

### 选项区域
- **显示**：当前仿真器的选项
- **隐藏**：其他仿真器的选项

## ❓ 常见问题

### Q1: 下拉菜单为空？
**原因：**
- 模型文件夹中没有对应文件
- 目录结构不正确

**解决：**
1. 检查目录结构
2. 确保有 `urdf/` 或 `mjcf/` 子目录
3. 确保文件扩展名正确

### Q2: 浏览按钮无响应？
**原因：**
- 文件选择器被其他窗口遮挡

**解决：**
1. 检查所有打开的窗口
2. 按Alt+Tab切换窗口

### Q3: 启动后没有反应？
**原因：**
- 终端窗口在后台
- 启动失败但没有提示

**解决：**
1. 检查终端窗口
2. 查看错误信息
3. 勾选"详细输出"重试
