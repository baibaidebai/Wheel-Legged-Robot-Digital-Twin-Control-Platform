**发布日期**: 2026-02-09

**状态**: Minimum Viable Product (最小可行产品)

---

## 📋 概述

轮腿机器人孪生控制系统MVP版本是一个功能完整的仿真控制平台，实现了从URDF模型加载、数字孪生映射、多后端仿真、控制算法到数据管理的完整工作流。本版本为后续硬件集成和算法研究提供了坚实的基础。

---

### 1. 机器人模型管理
- ✅ URDF模型加载和解析

## 🚀 快速开始

### 安装

```bash
# 克隆仓库
git clone https://github.com/baibaidebai/Wheel-Legged-Robot-Digital-Twin-Control-Platform.git
cd "Wheel-Legged Robot Digital Twin Control Platform"

# 安装依赖
pip install -r requirements.txt

# 构建ROS2包
colcon build
source install/setup.bash
```

### 启动仿真

```bash
# 方法1: 使用增强版GUI（推荐）
./launch_enhanced.sh

# 方法2: 使用标准GUI
./launch.sh

# 方法3: 命令行启动
./tools/launch_gazebo_safe.sh  # Gazebo
./tools/launch_mujoco.sh        # MuJoCo
```

### 运行演示

```bash
# LQR控制器演示
python3 scripts/demo_lqr_controller.py

# 数据记录演示
python3 scripts/demo_data_recorder.py

# 并行仿真演示
python3 scripts/demo_parallel_simulation.py
```

## 📊 性能指标

### 仿真性能
- **Gazebo**: ~50-100 Hz（取决于硬件）
- **MuJoCo**: ~200-500 Hz（单环境）
- **并行MuJoCo**: ~1000-2000 Hz（8环境）

### 控制性能
- **关节控制频率**: 100 Hz
- **IMU数据频率**: 200 Hz
- **状态同步延迟**: <10ms

### 资源使用
- **内存**: ~500MB-2GB（取决于环境数量）
- **CPU**: 2-8核心（取决于并行度）
- **磁盘**: ~10GB（包含模型和数据）

## ⚠️ 已知限制

### 当前限制
1. **依赖问题**: 需要手动安装torch用于PPO训练
2. **NumPy版本**: 与某些系统包存在版本冲突
3. **硬件要求**: Gazebo需要较好的显卡支持
4. **测试覆盖**: 部分集成测试因依赖问题暂时跳过

### 不支持的功能
- 硬件机器人直接控制（计划在后续版本）
- 分布式仿真（计划在后续版本）
- 实时视觉处理（计划在后续版本）
