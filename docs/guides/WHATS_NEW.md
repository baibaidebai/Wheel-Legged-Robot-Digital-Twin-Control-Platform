**界面预览：**

  - 安全模式（推荐虚拟机）

- 高级选项：
  - 详细输出
  - 强制软件渲染

#### 📁 目录重组

项目文件已重新组织，更加清晰专业！

**新的目录结构：**

```
项目根目录/
├── launch.sh              # 主启动脚本 ⭐
├── README.md              # 项目说明
├── tools/                 # 所有工具脚本
├── docs/guides/           # 所有用户文档
├── docs/                  # 技术文档
├── src/                   # 源代码
├── scripts/               # 演示脚本
├── test/                  # 测试文件
└── data/                  # 实验数据
```

**主要变化：**

1. **根目录简化**
   - 之前：20+个文件
   - 现在：只有核心文件

2. **工具脚本集中**
   - 所有 `.sh` 和 `.py` 脚本移到 `tools/`
   - 包括启动、安装、诊断、修复脚本

3. **文档分类**
   - 用户指南：`docs/guides/`
   - 技术文档：`docs/`

4. **新增GUI启动器**
   - `launch.sh` - 主启动脚本
   - `tools/launch_gazebo_gui.py` - GUI程序

**文件迁移对照：**

| 旧位置 | 新位置 |
|--------|--------|
| `./launch_gazebo_safe.sh` | `./tools/launch_gazebo_safe.sh` |
| `./install_gazebo.sh` | `./tools/install_gazebo.sh` |
| `./START_HERE.md` | `./docs/guides/START_HERE.md` |
| `./QUICK_FIX.md` | `./docs/guides/QUICK_FIX.md` |

#### 💡 为什么要重组？

**之前的问题：**
- 根目录太乱（20+个文件）
- 脚本和文档混在一起
- 难以找到需要的文件
- 不够专业

**现在的优势：**
- 根目录简洁（只有核心文件）
- 文件按功能分类
- 清晰的目录结构
- 更专业的项目组织
- 易于维护和扩展

#### 🎯 快速开始

**老用户：**
