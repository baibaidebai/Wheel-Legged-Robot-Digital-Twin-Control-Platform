## 🎯 使用场景导航

### 场景1：我是新手，第一次使用
1. 阅读 [START_HERE.md](START_HERE.md)
2. 运行 `./install_gazebo.sh`
3. 运行 `./launch_gazebo.sh`
4. 阅读 [GAZEBO_QUICKSTART.md](GAZEBO_QUICKSTART.md)

### 场景2：Gazebo窗口没有打开
1. 阅读 [QUICK_FIX.md](QUICK_FIX.md)
2. 运行 `./install_gazebo.sh`
3. 如果还有问题，阅读 [WHY_GAZEBO_DIDNT_OPEN.md](WHY_GAZEBO_DIDNT_OPEN.md)
4. 运行 `./check_gazebo.sh` 诊断

### 场景3：Gazebo闪屏/看不到模型
1. 阅读 [GAZEBO_FLICKERING_FIX.md](GAZEBO_FLICKERING_FIX.md)
2. 运行 `./check_opengl.sh` 检查渲染环境
3. 使用安全模式：`./launch_gazebo_safe.sh`
4. 如果还有问题，增加虚拟机显存

### 场景4：DM机器人无法加载
1. 阅读 [DM_ROBOT_FIX.md](DM_ROBOT_FIX.md)
2. 运行 `python3 fix_dm_urdf.py`
3. 重新启动：`./launch_gazebo_safe.sh`
4. 选择模型 2

### 场景5：安装失败
1. 阅读 [INSTALL_GAZEBO.md](INSTALL_GAZEBO.md) 的故障排除部分
2. 运行 `./check_gazebo.sh` 查看详细状态
3. 尝试手动安装命令
4. 查看 [WHY_GAZEBO_DIDNT_OPEN.md](WHY_GAZEBO_DIDNT_OPEN.md) 的故障排除

### 场景4：想了解项目功能
1. 阅读 [README.md](README.md)
2. 查看 [PROJECT_STATUS.md](PROJECT_STATUS.md)
3. 浏览 `docs/` 目录下的文档
4. 运行演示脚本

### 场景5：想开发和贡献
1. 阅读 [CONTRIBUTING.md](CONTRIBUTING.md)
2. 查看 [docs/FILE_ORGANIZATION.md](docs/FILE_ORGANIZATION.md)
3. 阅读 [docs/project_structure.md](docs/project_structure.md)
4. 查看源代码
