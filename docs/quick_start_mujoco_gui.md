
### 3. 控制机器人

#### 手动控制模式

1. **调整关节角度**: 拖动左侧的关节控制滑块
2. **观察效果**: 右侧MuJoCo窗口实时显示物理仿真
3. **重置姿态**: 点击"🔄 重置"按钮

#### 控制按钮说明

- **⏸️ 暂停/▶️ 播放**: 暂停或继续仿真
- **🔄 重置**: 重置机器人到初始姿态
- **⚙️ 重新配置**: 返回配置页面
- **🎥 启用/禁用渲染**: 切换渲染显示（提高性能）
- **📷 重置相机**: 重置相机视角

## 性能优化

### 如果渲染卡顿

1. **降低渲染频率**: 修改代码中的渲染定时器间隔
   ```python
   self.render_timer.start(50)  # 从33ms改为50ms (20 FPS)
   ```

2. **禁用渲染**: 点击"🎥 禁用渲染"按钮

3. **降低分辨率**: 在配置中调整渲染分辨率
   ```python
   render_width=640   # 改为 480
   render_height=480  # 改为 360
   ```

### 如果仿真太慢

1. **增加时间步长**: 在配置页面调整时间步长
   - 从 0.001s 改为 0.002s 或 0.005s

2. **选择高性能配置**: 选择 `high_performance` 配置档案

## 常见问题

### Q1: 启动后看不到MuJoCo渲染

**A**: 检查以下几点：
1. 确认选择了MuJoCo后端
2. 确认"启用渲染"选项已勾选
3. 查看控制台是否有错误信息
4. 确认MuJoCo已正确安装

### Q2: 渲染显示黑屏

**A**: 可能原因：
1. 模型加载失败 - 检查URDF文件路径
2. 渲染初始化失败 - 查看控制台错误
3. 等待几秒让仿真初始化完成

### Q3: 关节控制没有反应

**A**: 检查：
1. 确认选择了"手动控制"模式
2. 确认仿真处于"播放"状态（不是暂停）
3. 查看控制台是否有关节设置错误

### Q4: FPS很低

**A**: 优化方法：
1. 禁用渲染或降低渲染频率
2. 选择高性能配置档案
3. 关闭其他占用GPU的程序
4. 降低渲染分辨率
